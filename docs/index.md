# 飲み代家計簿（SakeLog）

お酒に使ったお金だけに特化した家計簿アプリです。
コンビニ酒・スーパー酒・外飲みを一元管理し、「誰と飲んだか」まで記録できます。

データはすべて端末内に保存され、外部のサーバーには送信されません。
